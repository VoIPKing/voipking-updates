# VoIPKing preview updates

Official preview update feed for the VoIPKing AWS image. This repository contains only curated release metadata, update packages and downloadable release notes; it does not expose the private development repositories.

Preview: clean image 0.10.2 to 0.10.3. The test update changes only the displayed application version. Use PBX System > Updates. Roll Back returns to 0.10.2. To repeat this exact update after rollback, launch a fresh clean image because replay protection rejects the same release.

This is a private production rehearsal being published for anonymous feed testing, not an AWS Marketplace production release. Preview signing trust is separate from future production signing. Do not use this preview feed for production.

Release notes are available as TXT and PDF in the release assets and in the PBX interface. The signed manifest binds the package SHA-256 and size. Existing third-party licenses in the image remain applicable; this preview does not change them.
